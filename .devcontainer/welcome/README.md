# 20x Playground

This Codespace is running your own private copy of the 20x Playground.

**This editor is not the playground.** The playground is a website. On a new Codespace it takes about eight minutes to start.

## Open The Playground

1. Watch the **Terminal** panel below this page. When the site is ready it prints `The 20x Playground is ready:` and a link.
2. Open that link.
3. Sign in with the GitHub account that opened this Codespace: choose **Get my code**, then enter the code on GitHub.

The playground pages are under `/playground`.

## Another Way In

Open the **Ports** panel, next to the Terminal, and choose the globe icon beside **Rampart 20x Playground**. Before the site has started, that address shows an error; wait and try again.

## If The Site Does Not Start

If the Terminal has printed no link after 20 minutes, please report it at
<https://github.com/unified-systems-com/rampart-20x-playground-tap/issues>.
